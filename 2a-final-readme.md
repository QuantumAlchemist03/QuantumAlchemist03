## 02 &nbsp;·&nbsp; Work

**[BSL-Fingerspelling-Recognizer](https://github.com/QuantumAlchemist03/BSL-Fingerspelling-Recognizer)** — real-time British Sign Language fingerspelling recognition
`MobileNetV2` `Flask` `OpenCV`
80%+ accuracy on live webcam input. Built for children with hearing impairments.

**[privacy-preserving-ai-healthcare](https://github.com/QuantumAlchemist03/privacy-preserving-ai-healthcare)** — federated learning + encryption framework
`Federated learning` `Encryption` `PyTorch`
Predictive accuracy held without patient records ever leaving their source.

**[orbit-watch](https://github.com/QuantumAlchemist03/orbit-watch)** — real-time satellite tracking
`SGP4` `FastAPI` `Leaflet` `GitHub Actions`
Live NASA Earth imagery, 43 tests, CI across Python 3.10 – 3.12.

**[CommunityEngageDB-Design](https://github.com/QuantumAlchemist03/CommunityEngageDB-Design)** — relational database system
`PostgreSQL` `Schema design` `Normalisation`
Event management, membership and community logistics for Together Culture Cambridge.
